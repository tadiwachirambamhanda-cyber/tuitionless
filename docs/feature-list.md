# Feature list: Scholarship Matcher

Source: `docs/prd.md`. One row per feature, in build order.

## Features

| ID | Feature (what a person can do or see) | Done check | Version | Status |
|---|---|---|---|---|
| F1 | Researched scholarships are stored in the database from a seed file, with source link and date checked | I run the seed and the database shows at least 100 scholarships from at least 8 countries, each with amount, eligible nationalities, level, deadline and an official link | v1 | not started |
| F2 | A student answers a step-by-step profile, one question at a time: nationality, university country and city, level, field, yearly budget and currency | On my phone I answer each question, go back and change one, and press "See my matches"; a missing answer shows a clear message | v1 | not started |
| F3 | The app matches the profile and groups results as Best fit, Worth a try and Stretch | I enter Kenyan, USD 4,000 a year, masters in Germany: every scholarship shown accepts Kenyans (or all nationalities), is for Germany or any country, and is for masters | v1 | not started |
| F4 | Each match shows a short reason it matched | Under each result I read a line such as "Open to Kenyan students. Covers masters in Germany, up to 11,208 EUR a year" | v1 | not started |
| F5 | I can filter and sort results (amount, deadline, country) | I sort by deadline and the soonest is first; I filter to one country and only that country remains | v1 | not started |
| F6 | I can open a scholarship to see full details and a link to apply | I tap View Details, see amount, coverage, eligibility and deadline, and the Apply button opens the official page | v1 | not started |
| F7 | Empty results explain what to change | I enter a very narrow profile and see "No matches yet. Try a higher budget or another country" instead of a blank page | v1 | not started |
| F8 | Student accounts and a saved shortlist (right after v1) | | later | not started |
| F9 | Deadline reminder emails | | later | not started |
| F10 | Admin screen to add and edit scholarships | | later | not started |
